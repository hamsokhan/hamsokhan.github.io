# منبع شعرها و افزودن شعر تازه

## منبع فعلی

متن هر ۱۶ شعر کتابخانه از **گنجور** (ganjoor.net) و از راه API عمومی آن (`api.ganjoor.net`) گرفته شده است. تاریخ دریافت هر شعر کنار خودش در `library.json` ثبت است: ۱۰ شعر نخست ۲۰۲۶-۱۱-۰۱ و ۶ شعر بعدی ۲۰۲۶-۱۱-۰۵. برای هر شعر این موارد ثبت می‌شود:

- نشانی دقیق صفحه، مثلاً `https://ganjoor.net/hafez/ghazal/sh1`
- شناسهٔ اثر در گنجور (`ganjoorId`) و عنوان کامل مسیر
- تاریخ دریافت و `textVersion`، که هش متن است و هر تغییر در متن، حافظهٔ توضیح‌ها را بی‌اعتبار می‌کند
- برای گزیده‌ها، بازهٔ بیت‌ها (`excerpt`) و یادداشت. مثال: «بنی آدم» فقط سه بیت پایانی حکایت ۱۰ باب اول گلستان است.

### آنچه عمداً برداشته نشده

گنجور برای بسیاری از بیت‌ها «خلاصه/معنی» دارد (`coupletSummary`). این‌ها نوشتهٔ معاصرند و حق استفادهٔ مستقل دارند، پس **کپی نشده‌اند**. حاشیه‌ها و دیدگاه‌های کاربران هم کپی نشده‌اند. فقط متن بیت‌ها گرفته شده است.

### دربارهٔ حق استفاده

متن دیوان سعدی و حافظ قدیمی است، اما متن گنجور از تصحیح‌های مشخصی گرفته شده و آوانگاری (اِعراب) آن کار ویراستاران گنجور است. پیش از انتشار عمومی، [شرایط استفاده و صفحهٔ «دربارهٔ» گنجور](https://ganjoor.net/about) را بخوانید و ارجاع به گنجور را، که اکنون در اپ نمایش داده می‌شود، حفظ کنید. این بررسی حقوقی کامل نیست و انجامش با صاحب پروژه است.

## افزودن شعر تازه به کتابخانه

۱. در گنجور صفحهٔ شعر را پیدا کنید و مسیر آن را بردارید (مثلاً `/hafez/ghazal/sh7`).
۲. یک ردیف به `src/data/library-manifest.json` اضافه کنید:

```json
{ "id": "hafez-ghazal-7", "poetId": "hafez", "title": "عنوان کوتاه", "form": "غزل", "ganjoorPath": "/hafez/ghazal/sh7" }
```

- `id` شناسهٔ پایدار است و بعد از انتشار عوض نمی‌شود، چون ذخیره‌ها و توضیح‌ها به آن وابسته‌اند.
- برای گزیده، `"couplets": [از, تا]` (شمارهٔ بیت در گنجور) و یک `note` توضیحی بگذارید.
- شاعر تازه را در `POETS` در `src/data/library.ts` اضافه کنید، با معرفی کوتاه و بررسی‌شده.

۳. فرمان دریافت را اجرا کنید:

```bash
npm run fetch-poems
```

۴. فایل `src/data/library.json` را بررسی کنید: متن هر بیت را با صفحهٔ گنجور مقایسه کنید.
۵. آزمون‌ها را اجرا کنید (`npm test`). شعر تازه را به فهرست `PUBLISHED_TEXT_VERSIONS` در `tests/text.test.ts` اضافه کنید تا متنش ناخواسته عوض نشود.
۶. اپ را دوباره منتشر کنید.

> `npm run fetch-poems` فقط شعرهایی را می‌گیرد که هنوز در `library.json` نیستند، تا افزودن یک شعر متن بقیه را عوض نکند. `npm run fetch-poems -- --refresh` همه را دوباره می‌گیرد. اگر گنجور متنی را ویرایش کرده باشد، `textVersion` آن شعر عوض می‌شود و توضیح‌های قبلی‌اش دیگر به متن تازه نسبت داده نمی‌شوند؛ این عمدی است، پس تازه‌سازی را فقط آگاهانه اجرا کنید.
