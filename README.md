# هم‌سخن

وب‌اپ شخصی فارسی (PWA) برای خواندن و فهم شعر کلاسیک: شعر را بخوان، روی بیت بزن، ساده بفهم و هرجا خواستی عمیق‌تر یاد بگیر.

- **اپ:** React + Vite + TypeScript. داده‌ها با IndexedDB روی همان دستگاه می‌مانند. اپ روی اندروید قابل نصب است و متن‌ها و توضیح‌های ذخیره‌شده بدون اینترنت هم در دسترس‌اند.
- **هوشواره:** اپ با کلید API خودتان مستقیم به Claude وصل می‌شود. سرور، حساب کاربری و Firebase در کار نیست.
- **نشانی منتشرشده:** https://mohammad100afghahi-ctrl.github.io/hamsokhan/ (GitHub Pages؛ با هر push به `main` به‌روز می‌شود)

## اجرا روی رایانه

```bash
npm install
```

حالت آزمایشی؛ پاسخ‌ها برچسب «پاسخ نمونه» دارند و هوشوارهٔ واقعی نیستند:

```bash
npm run dev:mock
```

حالت واقعی (کلید را در تنظیمات اپ وارد کنید):

```bash
npm run dev
```

بررسی‌ها:

```bash
npm test
```

```bash
npm run lint
```

```bash
npm run build
```

## کلید Claude

۱. در [console.anthropic.com](https://console.anthropic.com) یک کلید API بسازید. بهتر است فقط برای همین اپ باشد.
۲. در همان کنسول برای این کلید یا workspace آن **سقف هزینهٔ ماهانه** بگذارید. این تنها سقف واقعی است، چون سرور واسطه‌ای وجود ندارد.
۳. در اپ به «تنظیمات ← هوشواره (Claude)» بروید، کلید را وارد کنید و «بررسی اتصال» را بزنید. این بررسی توکنی مصرف نمی‌کند.
۴. در همان بخش مدل و سقف درخواست روزانهٔ این دستگاه را انتخاب کنید. پیش‌فرض: Sonnet 5.5 و ۶۰ درخواست در روز.

دربارهٔ امنیت کلید:

- کلید فقط در IndexedDB همان مرورگر ذخیره می‌شود و فقط به `api.anthropic.com` فرستاده می‌شود. در فایل پشتیبان نمی‌آید و دکمهٔ پاک‌کردن دارد. با پاک‌کردن دادهٔ مرورگر هم پاک می‌شود.
- هر کدی که روی همان «origin» (نشانی پایه) اجرا شود می‌تواند کلید را بخواند. همهٔ اپ‌هایی که روی `USERNAME.github.io` منتشر می‌کنید origin مشترک دارند. پس اپ‌های دیگرتان روی همان نشانی، از نظر فنی به کلید این اپ دسترسی دارند و این اپ هم به کلیدهای آن‌ها. اگر آن اپ‌ها را هم خودتان ساخته‌اید، خطرش کم است. برای جداسازی کامل، این اپ را روی نشانی جدا منتشر کنید (پایین را ببینید).
- اگر گوشی گم شد یا به کلید شک کردید، کلید را در کنسول Anthropic باطل کنید.

## انتشار

### گزینهٔ ۱: Cloudflare Pages (origin جدا، رایگان؛ پیشنهادی)

۱. کد را به یک مخزن GitHub (خصوصی هم می‌شود) push کنید.
۲. در [dash.cloudflare.com](https://dash.cloudflare.com) به Workers & Pages ← Create ← Pages ← Connect to Git بروید و مخزن را انتخاب کنید.
۳. فرمان build را `npm run build` و پوشهٔ خروجی را `dist` بگذارید.
۴. نشانی‌ای مثل `hamsokhan.pages.dev` می‌گیرید که origin مخصوص خودش است.

### گزینهٔ ۲: GitHub Pages

۱. مخزن را بسازید و push کنید. GitHub Pages در پلن رایگان فقط برای مخزن **عمومی** کار می‌کند. کلیدی در کد نیست، اما عمومی کردن مخزن تصمیم شماست.
۲. در Settings ← Pages، گزینهٔ Source را «GitHub Actions» بگذارید. workflow آماده در `.github/workflows/deploy.yml` با هر push به `main` آزمون‌ها را اجرا و اپ را منتشر می‌کند.
۳. نکتهٔ origin مشترک بالا را در نظر داشته باشید.

## نصب روی گوشی (Galaxy Z Fold 7)

نشانی اپ را در Chrome باز کنید و از منو «نصب برنامه» یا «افزودن به صفحهٔ اصلی» را بزنید. با تاشدن و بازشدن صفحه، چیدمان بین حالت تک‌ستونی و دوستونی (شعر کنار توضیح) عوض می‌شود. بیت انتخاب‌شده از دست نمی‌رود.
